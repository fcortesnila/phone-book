# Repository instructions

- Inspect the relevant application code, tests, configuration, and local instructions before editing.
- Preserve this project as a local portfolio demo. Do not add AI features, authentication, deployment, or production workflows unless explicitly requested.
- Use only synthetic names, phone numbers, emails, photos, and other contact data in code, examples, fixtures, and tests. Never add real personal or patient data.
- Add or update focused tests for behavior changes: use Vitest and React Testing Library for the frontend, and pytest for the FastAPI service.
- Keep changes scoped to the requested behavior and preserve the existing visual style unless a redesign is requested.
- In the final report, list the commands run and their results. Clearly identify any checks that could not be run and why.
